用户用**老唐（唐朝）估值法**做价值投资估值，偏好这套工作流：先过三大前提，预测三年后净利，套 `净利×合理PE(封顶25×)` 出合理估值/五折买点/卖点，再用现金流三尺子+水库验证。对"主业+投资组合"型公司（如腾讯）会额外要 **SOTP 分部加总**做交叉验证。

**Why**：他要的是可复用、可逐季更新、口径一致的跟踪工具，不是一次性结论。

**How to apply**：
- 交付物尽量给三件套并保持口径一致：MD 总览 + 带公式的 xlsx（每次改后跑 recalc.py）+ 交互 HTML（可发布为 artifact，方便随时查看、本地保存）。
- 估值必须用工具取**真实财报数据**，不臆造；缺失标"—"。
- 结论要清醒、给区间不给假精确，并提示关键假设(尤其合理PE)的敏感性；结尾写"本分析不构成投资建议"。
- 财报日可设一次性提醒任务自动更新跟踪。
- 技能库含 laotang-valuation、段永平视角、巴菲特视角，可按需切换。
